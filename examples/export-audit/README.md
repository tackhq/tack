# Export audit workflow

This example shows how to use `tack export` to produce a reviewable, standalone
shell script from a playbook — the artifact a security reviewer or an air-gapped
operator actually runs.

## Files

- `setup.yaml` — a small playbook that provisions a web host.
- `web01.sh` — the exported script, checked in for diff review.

## Generating the script

The script is exported deterministically (no timestamp, no fact gathering) so it
is byte-identical across runs and safe to commit:

```bash
tack export setup.yaml --host web01 --no-facts --no-banner-timestamp \
  --out-file web01.sh
```

Notes on this example's output:

- The `command` task guarded by `when: role == 'cache'` is pruned at export time
  (the variable is undefined for `web01`) and appears as a
  `# SKIPPED (when false): ...` comment — so reviewers can see the decision.
- The `apt` task's `loop`-free package list is emitted with per-package
  `dpkg-query` idempotency guards.

## Diff-review workflow

Treat the exported script like generated code: commit it, and let CI re-export
and fail on drift.

```bash
# In CI, regenerate and compare:
tack export setup.yaml --host web01 --no-facts --no-banner-timestamp \
  --out-file /tmp/web01.sh
diff -u web01.sh /tmp/web01.sh   # non-empty diff => playbook changed, re-review
```

Because export is deterministic with `--no-banner-timestamp`, any diff is a real
change in what will run on the host — not noise. Reviewers read the diff in shell
terms instead of re-deriving behavior from YAML. (The `# Generated by tack export
<version>` banner line reflects your installed tack version, so pin or normalize
it in CI if you compare across tack upgrades.)

## Validation gate

Fail the build if the playbook contains anything export cannot faithfully
represent:

```bash
tack export setup.yaml --host web01 --check-only
# exits non-zero and lists every UNSUPPORTED construct
```

## Running the script

The emitted script is self-contained bash under `set -euo pipefail`:

```bash
bash -n web01.sh    # syntax check
bash web01.sh       # apply (idempotent where the underlying modules are)
```
